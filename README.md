## ✨ Ключові фічі нового дизайну:
1. **Шрифт:** `Manrope` (заголовки) + `Plus Jakarta Sans` (текст) з повною підтримкою кирилиці.
2. **Перемикач тем:** Dark Pearlescent Titanium / Light Ceramic Pearl.
3. **Інтерактивна шахматка:** вибір квартир по поверхах зі статусами (Вільна, Резерв, Продана), 2D-кресленнями та розрахунком у EUR/BGN.
4. **Калькулятор розстрочки:** вноски за стадіями будівництва (Акт 14, Акт 16).
5. **Месенджери в 1 клік:** WhatsApp та Viber.
